# Sernau readable label review

At `72fead10`, 29 group labels and 27 module labels were compared with their pinned evidence. Where an abbreviated label omitted mathematical context, the revised wording names the result, object or condition the module defines or studies. The review covers whether each Explorer label describes its cited source.

All 776 other module titles were screened by group and length, with the shortest visible titles inspected in each group. The titles remain attributed to the upstream source. The cases below are candidates for a broader wording pass and would each need a source check before replacement. Show the module identifier and source link alongside each title, especially in search results, list rows and concise card views.
